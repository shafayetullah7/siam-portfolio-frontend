# Icons

Generated SVG icons as Solid components. **One file per icon**; public API is the barrel only.

- **Import:** `import { IconName } from "~/icons"`
- **Spec:** [../../../docs/design-tokens.md](../../../docs/design-tokens.md) (Icons section)
- **Shared props:** `./types.ts` → `IconProps`

Add each new icon to `index.ts`.
